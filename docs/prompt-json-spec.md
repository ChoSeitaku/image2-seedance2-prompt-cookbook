# prompt.json Specification

## Overview

`prompt.json` is the standardized format for storing prompt templates in this project. Each prompt is represented by a single `prompt.json` file that contains all metadata, multilingual prompt text, variable definitions, and example cases.

## Naming Convention

- File name: always `prompt.json`
- Directory name: the prompt's `slug` (lowercase, hyphen-separated, e.g. `cinematic-rainy-portrait`)
- Parent directory: the prompt's `category` (e.g. `portrait`, `cinematic`)

## Directory Structure

```
<model>/
└── <category>/
    └── <slug>/
        ├── prompt.json
        ├── source.md
        └── example.jpg
```

## Image2 prompt.json Fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `prompt_name` | string | yes | Human-readable prompt name |
| `prompt_slug` | string | yes | URL-safe slug (kebab-case) |
| `model` | string | yes | Fixed value: `"Image2"` |
| `version` | string | yes | Semantic version of the prompt |
| `category` | string | yes | Category directory name |
| `language` | string[] | yes | Supported languages (min: `["zh", "en"]`) |
| `summary` | object | yes | `{ "zh": "...", "en": "..." }` — short description |
| `use_case` | object | yes | `{ "zh": [...], "en": [...] }` — list of use cases |
| `preview` | object | yes | `{ "image": "example.jpg" }` — relative path to preview |
| `prompt_template` | object | yes | `{ "zh": "...", "en": "..." }` — template with variables |
| `negative_prompt` | object | yes | `{ "zh": "...", "en": "..." }` — negative prompt text |
| `variables` | object | yes | Variable definitions (see below) |
| `example_cases` | array | yes | List of filled example cases |
| `recommended_aspect_ratio` | string[] | yes | Recommended aspect ratios |
| `recommended_parameters` | object | yes | Recommended generation parameters |
| `tags` | string[] | yes | Search/filter tags |
| `created_at` | string | yes | ISO 8601 creation date |
| `updated_at` | string | yes | ISO 8601 last update date |
| `license` | string | yes | License identifier (default: `"MIT"`) |

### Image2 Variable Fields

Each variable has the following fields:
- `zh` — Chinese label
- `en` — English label
- `example_zh` — Example value in Chinese
- `example_en` — Example value in English

Standard Image2 variables: `SUBJECT`, `LOCATION`, `COMPOSITION`, `CAMERA_ANGLE`, `LIGHTING`, `COLOR_PALETTE`, `STYLE`, `TEXTURE`, `MOOD`

## Category Naming

Category directory names must be lowercase with hyphens (kebab-case). They should match one of the predefined categories:

**Image2:** `portrait`, `product`, `poster`, `character`, `architecture`, `style`, `sticker`

**Seedance 2:** `cinematic`, `product-video`, `camera-movement`, `character-motion`, `image-to-video`, `social-video`

## Image Naming

- Preview images in the prompt directory must be named `example.jpg` or `example.png`
- The `preview.image` field in prompt.json stores the relative filename (e.g. `"example.jpg"`)
- This is a relative path from the prompt.json file's location

## README Gallery Convention

- README files contain `<!-- PROMPT_GALLERY_START -->` and `<!-- PROMPT_GALLERY_END -->` markers
- The gallery content between these markers is auto-generated by `npm run update-readme`
- Gallery entries link to the prompt's directory (not directly to prompt.json)
- Do not manually edit content between the gallery markers
